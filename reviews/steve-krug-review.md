# Steve Krug Usability Review

## Route: /
- 5-second test: Clear that it's a youth development nonprofit. Hero copy is bold and understandable.
- Primary user: Donors, volunteers, community members.
- Primary action: Donate (Gold button).
- What is clear: The mission, the programs, the call to action.
- What is confusing: The anchor links in the navigation behave unexpectedly if a user is not on the homepage (this was mitigated by creating stub pages).
- Unnecessary words: "Elevate. Empower. Asc3nd." is slightly generic but acceptable for brand tagline.
- Navigation friction: Anchor links vs separate pages.
- CTA friction: Low. Buttons are distinct.
- Mobile friction: Hamburger menu is functional, language toggle fits well.
- Accessibility friction: Contrast is generally good (white on black/gold).
- Recommended fix: Convert all sections to distinct pages if content grows, or ensure robust scrolling functionality across routes.
- Can fix now under scope? yes (stubbed pages).
